# rekha — the public API

> **Frozen as of 0.9.0** (2026-09-21). Every name on this surface keeps its signature and its
> documented answer through 1.x. Additions are additive; a removal, a rename or a change to a
> documented answer is a major version.

This is the reference for what a consumer of `dist/rekha.cyr` (or `dist/rekha-woff.cyr`, or the
data module `fonts/face_data.cyr`) may call: **178 functions and 72 constants** in the bundle, 10
functions in the data module, and the nine members of `RekhaErrCode` — the count
[`surface.txt`](surface.txt) carries, generated by `scripts/api_surface.py` and gated in CI.
The source headers in `src/` stay the normative text: where a page and a header disagree, the
header is right and the page is a bug. For *why* rekha is shaped this way see
[`docs/adr/`](../adr/); for what shipped when, [`CHANGELOG.md`](../../CHANGELOG.md).

## The boundary is enforced, not described

The bundle begins with a `private` declaration ([`src/freeze.cyr`](../../src/freeze.cyr)), so
every function and constant not marked `public` in `src/` is unreachable from a consumer's code —
the compile error is `'rekha_rd_u16' is private to its file`. Nothing has to be remembered:
if it links, it is on this surface. That needs **cyrius 6.6.6 or later** (the visibility keywords
are 6.5.0, their whole-file semantics 6.6.5), which the one-leaf sidecar already required.
Enum constants (`REKHA_OK` …) are always reachable, by the language.

| You are … | Read … |
|---|---|
| Drawing text: a face in memory, a string, a sadish canvas | [`open.md`](open.md) → [`metrics.md`](metrics.md) → [`outline.md`](outline.md); then [`kern.md`](kern.md) |
| Rendering at small sizes and want the hinted outline | [`hint.md`](hint.md) — the five rules first |
| Loading a web font (WOFF 1.0 / WOFF2) | [`open.md`](open.md) § WOFF, with `dist/rekha-woff.cyr` |
| Building a font picker, or a variable-font UI | [`names.md`](names.md), [`variations.md`](variations.md) |
| A freestanding kernel that wants a face at boot | [`open.md`](open.md) § The embedded default face |
| Asking why a call answered nothing | [`errors.md`](errors.md) |

## The six rules

**1. One handle, one thread, no free.** `rekha_font_open` returns a `RekhaFont` — an opaque
pointer to `REKHA_FONT_SIZE` bytes that borrows the caller's font buffer and caches table
offsets from it. The buffer must outlive the handle and must not change under it. A handle is
used by one thread at a time (its error slot, its variation state and its hint context live on
it). Nothing in rekha is freed: every allocation goes through sadish's `sd_alloc` hook
([ADR 0001](../adr/0001-the-sadish-seam-and-sd-alloc.md)), so a consumer that scopes an arena
per frame must open faces, warm the hint context and load one glyph of a variable face
*outside* that scope. The calls that allocate say so in their entry; the rest allocate 0 B.

**2. Test the answer first, ask `rekha_font_error` second.** A refusal is a sentinel — `0` for
a handle, a count, a pointer or a metric; an empty path or an empty outline for a glyph — and
the *reason* is on the handle: `rekha_font_error(font)` is a `RekhaErrCode` and
`rekha_font_error_detail(font)` a static string naming the table or field. Every public call
that can refuse clears the slot on entry, so a code describes the call you are holding.
`0` from a metric reader means *unknown*, not *zero*: the code tells them apart (`REKHA_OK`
with a legal zero). The open family has no handle to record into, so `rekha_font_open_why` and
`rekha_font_open_index_why` take a caller's slot instead ([`errors.md`](errors.md)).

**3. Units.** Design units (the em square is `rekha_units_per_em`) for everything a table
states; **pixels** from the `_px` readers, rounded half up — `(v × px_size + upem/2) / upem`;
**16.16 fixed point** from the `_fx` readers and everything sadish takes (`SD_ONE = 65536`);
the hinted layer works in **F26Dot6** (26.6, 64 = one pixel) and its `_px` advance is a whole
pixel. `>>` in Cyrius is logical — never shift a negative coordinate; sadish exports `sd_asr`.

**4. Refuse, don't guess.** A malformed table, a lying offset, a cap exceeded, or bytecode that
contradicts itself yields the sentinel and a code — never a plausible wrong number
([ADR 0002](../adr/0002-refuse-dont-guess.md)). The caps are part of that contract and are
stated as values, not names: an outline holds at most **4,096 points** and **128 contours**;
a composite nests **5** deep and may load **64** glyphs / **16,384** points per
`rekha_load_glyph`; a collection has at most **1,024** faces; the hint machine runs at most
**1,000,000** instructions per program at a `CALL` depth of **64**, and takes a `maxp` that
declares at most 8,192 stack elements, 8,192 storage slots, 4,096 functions, 256 instruction
defs, 16,384 control values and 4,096 twilight or glyph points; WOFF inflation is capped at
1,032:1 and WOFF2 at what the header declares.
A hinting refusal never draws a partially hinted glyph: the outline comes back unhinted.

**5. The sadish seam.** rekha never rasterizes. `rekha_char_to_sdpath` /
`rekha_glyph_to_sdpath` / `rekha_outline_to_sdpath` / `rekha_hint_to_sdpath` emit an `SdPath`
(move / line / quad / cubic / close; the font's y-up flipped to sadish's y-down) positioned
at a 16.16 origin, which `sd_canvas_fill_path` fills. A refusal is an **empty path**, so a run
never stops drawing.

**6. What is NOT promised.** Every name without `public` (the byte readers, the parsers, the
interpreter's internals, the test seams `rekha_hint_run` / `rekha_hint_load_simple`); the
layout of every record except `RekhaOutline` ([`outline.md`](outline.md)); the *value* of
`REKHA_FONT_SIZE` (frozen by name — it may grow in a minor release, size by the name); the
identifiers of the caps above; `programs/`, `scripts/` and the generated oracle modules; the
default face's *bytes* beyond what `rekha_face_default_verify` promises. A variable face is
hinted off-reference (no `cvar`), `hdmx` is not read, and CFF's own hints are discarded — all
stated in [`hint.md`](hint.md), all frozen as stated.

## Stability promise

- **Within 1.x**: no documented function is removed or renamed; no signature changes; no
  documented answer changes its meaning; no documented constant is removed. A constant's *name*
  is frozen; where its value may move, the entry says so.
- **Additions** (a new function, a new constant, a new enum member) may arrive in any minor
  release and are listed in `surface.txt` and the CHANGELOG when they do.
- **Fixes**: a documented answer that was measured wrong against a font's own tables or against
  FreeType is a bug, fixed in a patch release and recorded with the measurement.
- **Consumers below cyrius 6.6.6** cannot compile the bundle (`private` / `public` are reserved
  words from 6.5.0). The sadish floor is 0.11.2.
